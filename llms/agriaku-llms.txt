# AgriAku

> AgriAku (PT Agriaku Digital Indonesia) is a Jakarta-based agritech company founded in
> 2021 that digitizes the distribution of agricultural inputs to Indonesia's network of
> independent farm-supply shops. It operates no public API.

AgriAku connects crop-input manufacturers to more than 23,390 independent farm-supply
shops (toko tani) across Indonesia. Partner shops order from a catalog of 15,000+
products — seeds, fertilizers, crop protection, nutrients and farm tools — through the
AgriAku Mitra Android application. Separate first-party applications cover the rest of
the chain: a vendor platform, a seller web portal, and AgriAku Logistik Kurir for the
couriers who move goods to partner shops.

## Developer surface

AgriAku publishes **no** public API. This is a measured finding, not an assumption:

- No developer portal, API reference, or getting-started guide exists on agriaku.com or
  on any subdomain reachable from certificate-transparency records.
- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, Postman collection or JSON Schema is
  published anywhere. The probes at /openapi.json, /openapi.yaml, /swagger.json,
  /api-docs and /graphql on agriaku.com all return 404.
- No MCP server, no A2A agent card, no llms.txt of the company's own, and no document at
  any named /.well-known/ path on any AgriAku host.
- No client SDK exists in npm, PyPI, RubyGems or crates.io, and the company's GitHub
  organization (https://github.com/Agriaku) contains only forks of upstream Flutter and
  Kotlin libraries used inside its own Android apps.
- api.agriaku.com exists as a DNS record but is a dangling CNAME: it points at
  agriaku-api-1367161307.ap-southeast-1.elb.amazonaws.com, an AWS load balancer that no
  longer resolves to any address. It was never a documented public surface.
- The company's own web properties are gated applications, not developer surfaces:
  vendor.agriaku.com (vendor platform), seller.agriaku.com, erp.agriaku.com (a
  self-hosted Odoo instance — vendor software, not AgriAku's contract), and
  agriaku.com/wp-json/ (the marketing site's WordPress REST API, which returns 401).

An agent looking for a programmatic route into AgriAku will not find one. The contact
path is human: cs@agriaku.com, info@agriaku.com, or the form at
https://agriaku.com/contact-us/.
